# Skystore — интернет-магазин

Проект интернет-магазина для продажи плагинов, примеров кода и сервисов.

## Стек
- Python 3.12
- Django
- Bootstrap 5

## Как запустить
1. `python -m venv venv`
2. Активировать виртуальное окружение.
3. `pip install -r requirements.txt`
4. `python manage.py runserver`

## После запустить в браузере 
http://127.0.0.1:8000/ — должна открыться страница home.html с карточками и Bootstrap-стилями.
http://127.0.0.1:8000/contacts/ — страница контактов с формой.
