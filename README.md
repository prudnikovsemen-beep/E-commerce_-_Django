# Skystore — интернет-магазин с блогом

Проект интернет-магазина для продажи плагинов, примеров кода и сервисов.
Реализована базовая структура каталога (категории и товары), раздел блога
для SEO-продвижения, административная панель, загрузка тестовых данных
через фикстуры и кастомную команду, работа с PostgreSQL.

## Стек

- Python 3.12
- Django 6.1.2
- PostgreSQL
- psycopg2-binary
- Pillow (для работы с изображениями)
- django-ckeditor-5 (современный визуальный редактор текста статей блога с поддержкой загрузки файлов)
- Poetry (управление зависимостями)
- Poetry (управление зависимостями)
- Bootstrap 5 (стилизация)

## Как запустить проект

1. **Создать виртуальное окружение и установить зависимости:**

   poetry install

## Применить миграции и запустить сервер:

## Доступ к страницам
```bash
http://127.0.0.1:8000/ — главная страница с последними товарами (Bootstrap 5).
http://127.0.0.1:8000/contacts/ — страница контактов с формой обратной связи. Контактные данные (страна, ИНН, адрес, телефон, email) редактируются через админку (модель «Контактные данные» приложения catalog).
http://127.0.0.1:8000/blogs/ — список опубликованных статей блога.
http://127.0.0.1:8000/blogs/create/ — создание новой блоговой записи.
http://127.0.0.1:8000/blogs/<id>/ — просмотр статьи (счётчик просмотров увеличивается при каждом открытии).
http://127.0.0.1:8000/blogs/<id>/update/ — редактирование статьи (после сохранения — перенаправление на страницу отредактированной статьи).
http://127.0.0.1:8000/blogs/<id>/delete/ — удаление статьи.
http://127.0.0.1:8000/admin/ — административная панель (доступ после входа как суперпользователь).
