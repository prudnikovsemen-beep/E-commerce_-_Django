# Интернет-магазин с блогом

Проект интернет-магазина для продажи.

Реализовано:
- базовая структура каталога (категории и товары);
- галерея фотографий товара (основное фото + дополнительные снимки с переключением);
- блог с двумя типами публикаций — «Статья» и «Видео» — и поднавигацией «Лента / Статьи» (раздел «Видео» — в разработке);
- автоподбор товаров из каталога к каждой публикации: по словам из заголовка находятся товары в наличии и выводятся каруселью под текстом (если товаров в наличии нет — карусель не показывается);
- счётчик просмотров публикаций; при достижении 100 просмотров администратору уходит поздравительное письмо;
- регистрация пользователей с отправкой приветственного письма;
- вход и выход из аккаунта (выход реализован POST-запросом для защиты от CSRF);
- шапка сайта адаптируется под статус пользователя: аноним видит «Вход» и «Регистрация», авторизованный — свой email со ссылкой в личный кабинет и кнопку «Выход»;
- личный кабинет — редактирование профиля (email, телефон, аватар, страна), доступен только авторизованным пользователям;
- административная панель;
- загрузка тестовых данных через фикстуры и кастомную команду;
- работа с PostgreSQL.

## Стек

- Python 3.12
- Django 6.1.2
- PostgreSQL
- psycopg2-binary
- Pillow (для работы с изображениями)
- django-ckeditor-5 (визуальный редактор текста статей блога с поддержкой загрузки файлов)
- Poetry (управление зависимостями)
- Bootstrap 5 (стилизация)

4. ** Доступ к страницам**
```bash
- http://127.0.0.1:8000/ — главная страница с последними товарами (Bootstrap 5);
   - http://127.0.0.1:8000/catalog/ — каталог товаров с разбивкой по категориям;
   - http://127.0.0.1:8000/catalog/category/<id>/ — товары выбранной категории;
   - http://127.0.0.1:8000/catalog/product/<id>/ — карточка товара с галереей фото (основное фото + ProductImage, переключение миниатюрами и стрелками «‹ ›»);
   - http://127.0.0.1:8000/contacts/ — страница контактов с формой обратной связи. Контактные данные (страна, ИНН, адрес, телефон, email) редактируются через админку (модель «Контактные данные» приложения catalog);

   - http://127.0.0.1:8000/users/login/ — вход в аккаунт (после входа — перенаправление на главную страницу);

   - http://127.0.0.1:8000/blogs/ — лента блога: все опубликованные публикации (статьи и видео) в порядке даты, с поднавигацией «Лента / Статьи»;

   - http://127.0.0.1:8000/blogs/<id>/delete/ — удаление публикации;
   - http://127.0.0.1:8000/admin/ — административная панель (доступ после входа как суперпользователь).![img_1.png](img_1.png)
