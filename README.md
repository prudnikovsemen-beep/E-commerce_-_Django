# Skystore — интернет-магазин

Проект интернет-магазина для продажи плагинов, примеров кода и сервисов. Реализована базовая структура каталога (категории и товары), админка, загрузка тестовых данных через фикстуры и кастомную команду, работа с PostgreSQL.

## Стек

- Python 3.12
- Django 6.1.2
- PostgreSQL
- psycopg2-binary
- Pillow (для работы с изображениями)
- Poetry (управление зависимостями)
- Bootstrap 5 (стилизация)

## Как запустить проект

1. **Создать виртуальное окружение и установить зависимости:**
   ```bash
   python -m venv venv
   poetry install

### Убедиться, что база данных создана:
В PostgreSQL должна существовать 
база данных myproject_db и пользователь myuser с правами на неё.

### Применить миграции: 
   
    python manage.py migrate
    
### Создать суперпользователя: 
   
    python manage.py createsuperuser

### Запустить сервер:
    python manage.py runserver

##Доступ к страницам

http://127.0.0.1:8000/ — главная страница с карточками товаров (Bootstrap 5).
http://127.0.0.1:8000/contacts/ — страница контактов с формой обратной связи.
http://127.0.0.1:8000/admin/ — административная панель (доступ после входа как суперпользователь).
