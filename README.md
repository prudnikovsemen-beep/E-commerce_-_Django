## Инструкция по запуску

1.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
2.  Настройте переменные окружения в файле `.env` (DB_NAME, DB_USER, DB_PASSWORD и т.д.).
3.  Примените миграции:
    ```bash
    python manage.py migrate
    ```
4.  Запустите сервер:
    ```bash
    python manage.py runserver
    ```

## Структура проекта

-   `ecommerce_project/`: настройки проекта (`settings.py`, `urls.py`).
-   `products/`: приложение с моделями, представлениями и шаблонами товаров.
-   `templates/`: глобальные шаблоны (включая `base.html`).
-   `media/`: загрузка изображений товаров.
